# 2026 高教社杯 B 题 · 解题思路与指导

> 题目：无线电干扰源的快速自动定位与清除
> 目标区域：以原点为圆心、半径 1800 m 的圆域；x 轴正东，y 轴正北；干扰源 10~16 个，个数未知。
> 本文给出四问的建模思路、核心公式、算法与工程落地要点。

---

## 0. 全局设定与统一符号

| 符号 | 含义 | 取值 / 说明 |
|---|---|---|
| `S_i` | 第 i 个检测点坐标 | 机器人可到达的任意点 |
| `θ_i` | 在 `S_i` 处测得的**示向度** | [0°,360°)，正东为 0°，逆时针为正 |
| `ε` | 示向度误差半宽 | **1°**，`θ = β_true + δ`，`δ ∈ [−1°,1°]` |
| `R` | 干扰源有效接收半径 | [1000, 1500] m，**每源不同且不可读出** |
| `v` | 移动速度 | 5 m/s（沿直线） |
| `C` | 频道集合 | 20 个频道，每频道至多一个源 |
| `N` | 干扰源总数 | 10~16，**未知** |
| `D` | 目标圆域 | `x² + y² ≤ 1800²` |

**动作耗时（均计入虚拟时间）**

| 动作 | 耗时 | 备注 |
|---|---|---|
| 移动 | 位移 / 5 m/s | |
| 切换频道 | 1 s / 次 | **只由 `/measure` 的 channel 触发** |
| 检测 | 5 s | `/measure`，移动过程不计检测 |
| 清除（命中） | 5 s | = 光学精确定位 3 s + 激光清除 2 s |
| 清除（未命中） | 3 s | 只做光学精确定位 |
| `/enter`、`/exit` | 0 s | 不推进虚拟时钟 |

**两个贯穿全题的"信息结构"结论（务必写进论文）**

1. **测向机只输出"方向"，没有距离、没有场强。** 唯一与距离有关的信息是 `/measure` 返回 `near`（距离 ≤ 5 m 且位于覆盖角内）。所以本题本质是 **纯 AOA（测角）定位**。
2. **误差是"位置固定偏差"，不是随机噪声。** 同一地点重复检测结果完全不变（可以"二值确认"但不能"多次平均降噪"）。因此：
   - 在同一点重复测同一频道 = **白花 5 s**；
   - 想减小定位区域，**必须换到新位置**再测。

## 1. 问题 1：交会定位区域的直径与覆盖圆

### 1.1 建模：定位区域 = 角扇形的交集

在 `S_i` 处测得示向度 `θ_i`，真实方位角 `β_i = θ_i − δ_i`，`|δ_i| ≤ 1°`。故干扰源 `G` 必位于以 `S_i` 为顶点、方向 `θ_i`、**半角 ε = 1°** 的角扇形（楔形）内：

```
W_i = { P : angle(P − S_i) ∈ [ θ_i − ε , θ_i + ε ] }
```

于是

```
K = ⋂_{i=1..n} W_i        （定位区域）
```

**关键性质：**

- 每个楔形 = 两个半平面的交集 → **凸集**；凸集的交仍为凸 → **K 是凸多边形**。
- 每个楔形贡献 ≤ 2 条边 → **顶点数 ≤ 2n**；n = 2 时为四边形（即题图 2 的红色四边形）。
- **必做的额外裁剪**（否则会得到无穷大区域）：
  - 目标圆域 `D`（源必在圆内）；
  - 每个源可被检出 ⇒ `|G − S_i| ≤ R ≤ 1500`，即以 `S_i` 为心、**1500 m 为半径的圆**再交一次——这一步能显著收紧区域，是很自然的加分点。
- 若交集为空 ⇒ 说明这些示向度**不可能来自同一个源**（或某点误差超出 ±1°），应作为**相容性检验**输出。

### 1.2 算法：凸多边形裁剪 + 旋转卡壳

**步骤（半平面裁剪 / Sutherland–Hodgman）**

```
输入: {(S_i, θ_i)}_{i=1..n}, ε = 1°, 目标圆域 D
1) P ← 用 720 边多边形逼近 D（半径 1800），或先取大包围盒（便于发现无界）
2) for i = 1..n:
       for α in { θ_i − ε , θ_i + ε }:
           n̂ = ( −sinα , cosα )                     # 该方向射线的左法向
           if α == θ_i − ε:  保留 { P : (P−S_i)·n̂ ≥ 0 }   # 下边界左侧
           else:             保留 { P : (P−S_i)·n̂ ≤ 0 }   # 上边界右侧
           P ← Clip(P, 该半平面)
       P ← P ∩ disk(S_i, 1500)                       # 由"能测到"推出的上界
       if P == ∅: 输出"不相容"，退出
3) 输出凸多边形 K 的顶点序列 V = {v_1,…,v_m}，m ≤ 2n
```

复杂度 `O(n·m)`，n ≤ 10 量级，可实时计算。

**直径**

- 凸多边形直径必由一对**顶点**取得：`d = max_{j<k} ‖v_j − v_k‖`。
- m 很小（≤ 20）直接两两枚举即可；要写得漂亮可用**旋转卡壳** `O(m)`。

### 1.3 第二问："以区域直径为直径的圆能否覆盖此区域？"

**（a）一般结论：不能保证。**
记 `r*` 为 K 的**最小覆盖圆（MEC）半径**。由 Jung 定理

```
d/2 ≤ r* ≤ d/√3 ≈ 0.577 d
```

以 `d` 为直径的圆半径为 `d/2`，能覆盖 K **当且仅当 `r* = d/2`**，即直径两端点恰是 MEC 的**对径点**。否则必须放大到 `2r*` 才能覆盖。
**反例**：边长 `d` 的正三角形的 `r* = d/√3 > d/2`，以 `d` 为直径的圆覆盖不了。

**（b）分层结论（关键！必须区分测点数 n，不能一句话带过）。**

先给出一个可证的引理：

> **引理（平行四边形）** 任意平行四边形，以其**较长对角线为直径**的圆一定覆盖该平行四边形。
> 证明：顶点设为 `0, u, v, u+v`，设 `|u+v| ≥ |u−v| ⟺ u·v ≥ 0`。圆心 `c = (u+v)/2`，`r = |u+v|/2`。
> `|u − c| = |u − v|/2 ≤ r`，`|v − c| = |v − u|/2 ≤ r`，故四顶点均在圆内。∎

这条引理解释了"**为什么两站没问题**"，但不能推广到多站。实测结论如下。

**情形 ①：n = 2（题图 2 的情形）—— 可以认为能覆盖。**
两站楔形交会是"双楔形风筝四边形"，与平行四边形只差 `O(ε)` 量级。
隔离实验（`ε = 1°`，**不做任何圆盘裁剪**，19 万组有效样本）：

| 指标 | 结果 |
|---|---|
| 中位 `E = 2r*/d − 1` | `2.2e−16`（机器精度 ⇒ 严格覆盖） |
| p99 | `2.7e−15` |
| p99.9 | `2.5e−4` |
| 最大 `E` | `5.9e−4`（半径仅差 **0.06%**） |
| `P(E > 1e−3)` | `0`（0/190668） |

即：**绝大多数配置下严格覆盖，最坏情况也只在半径上差 0.06%**，工程上可视为能覆盖。

**情形 ②：n ≥ 3 —— 不能保证。**
多个楔形交会时，区域可能退化成**三角形**。三角形被其直径圆覆盖 ⟺ 三角形为钝角或直角；**锐角三角形就会失败**，正三角形最差：

```
E_max = 2/√3 − 1 = 0.154701   ← 恰好达到 Jung 上界
```

对抗性搜索在 `ε = 1°` 时就找到了达到该上界的**精确反例**（见下），随机 Monte-Carlo 中 `n = 3`、`ε = 1°` 也有约 **2.9%** 的配置出现 `E > 1%`。

**可引用的具体反例（ε = 1°，三站交会）**

```
S1 = (0.00, 0.00)      示向度 = −0.999838°      δ1 = −0.9998°
S2 = (335.60, 550.64)  示向度 = −58.999838°     δ2 = +0.9998°
S3 = (451.84, −350.93) 示向度 = +61.000162°     δ3 = +0.8860°
源 G = (653.52, 0)
区域为边长 0.94 m 的等边三角形：
  d = 0.935 m,  d/2 = 0.468 m,  r* = 0.540 m,  2r*/d = 1.154701 = 2/√3
  某一顶点到直径圆圆心的距离 = 0.810 m > d/2 = 0.468 m  →  明显落在圆外
```

**情形 ③：若额外用"有效接收半径圆"收紧区域**，边界会出现**圆弧**。当区域是极端细长的条带、末端被圆弧"顶起"时，`E` 可达 `~1e−2`（罕见）。
对照实验说明这不是离散化假象：圆盘近似取**内接**与**外接**两种（分别使区域偏小 / 偏大），失败率几乎相同（`n = 2, ε = 1°` 时 15.5% vs 15.0%），故该效应真实存在。

**（c）论文里建议的写法（四段式）**

1. **严格判据**：`r* = d/2 ⟺ 能覆盖`；一般反例用正三角形；并给出 Jung 界 `d/2 ≤ r* ≤ d/√3`。
2. **引理**：证明平行四边形引理（解释两站为何安全）。
3. **数值实验（Monte-Carlo）**：按 `n` 分层报告，统计量用 `E = 2r*/d − 1`（不要只数失败次数），并给出 `E` 的分位数与最大值；**必须做内接/外接对照**以排除离散化假象。
4. **对抗性验证**：用优化器主动最大化 `E`。`n = 2` 只能推到 `6e−4`；`n ≥ 3` 能精确推到 `2/√3 − 1`，说明结论分层是本质的。
5. **实践建议**：不要只报 `d`，而应**同时报最小覆盖圆半径 `r*`**——它的直径 `2r*` 必然覆盖区域，且最多比 `d` 大 15.5%。

### 1.4 边界情况与讨论

- **n = 1**：单楔形无界，必须靠 `D` 与 `disk(S_1,1500)` 裁剪，且此时**无法定位**（只能定方向）。
- **交会角（cut angle）α 退化**：两点示向度近乎平行时，K 被拉成长条形，`d` 很大 → 问题 2 要解决的正是这个。
- **相容性检验**：交集为空 / 面积异常大，是算法自我诊断的重要信号。

### 1.5 为什么"交会角越接近 90° 越好"（严格推导）

这一问的答案要用**测角定位的线性化最小二乘 + 信息矩阵（GDOP）分析**，而不是靠直觉。

**（1）信息矩阵推导**

观测方程 `β_i = atan2(y − y_i, x − x_i) + δ_i`，一阶线性化后

```
∇β_i = n_i / r_i          n_i 为 r_i 方向（视线）的单位法向
H 的第 i 行 = (1/r_i)·n_iᵀ
HᵀH = Σ_i (1/r_i²) n_i n_iᵀ
```

两站时取 `n₁=(1,0)`、`n₂=(cosα, sinα)`（`α` 为交会角），记 `a = 1/r₁²`、`b = 1/r₂²`：

```
HᵀH = [[a + b·cos²α , b·cosα·sinα],
       [b·cosα·sinα , b·sin²α    ]]
det(HᵀH) = a·b·sin²α = sin²α / (r₁² r₂²)
```

于是

```
Cov(p̂) = σ² (HᵀH)⁻¹
det(Cov)     = σ⁴ r₁² r₂² / sin²α          →  sqrt(det Cov) = σ² r₁ r₂ /|sin α|
trace(Cov)   = σ² (r₁² + r₂²) / sin²α       →  GDOP = √(r₁²+r₂²) /|sin α|
```

两个标量都在 `sin α = 1`，即 **`α = 90°`** 取到最小值。这就是严格版的"越接近 90° 越好"。

**（2）几何等价解释**

测角误差 `±σ` 使每条视线绕测点旋转，在目标附近形成"宽 `2σr_i` 的窄带"；两条窄带夹角为 `α`，相交得到平行四边形，边长 `2σr₁/sinα`、`2σr₂/sinα`，**面积 `= 4σ²r₁r₂/sinα`** —— 与信息矩阵结论一致（差一常数）。

```
α = 90°  ⟺  目标落在以 S₁S₂ 为直径的圆上（Thales 定理）
         ⟺  第二点位于"过源、且垂直于第一视线"的那条直线上
```

**（3）数值验证（`gdop_cutangle.py`，`r₁ = r₂ = 1000 m`、`ε = 1°`）**

| 交会角 α | 10° | 20° | 30° | 45° | 60° | 90° | 120° | 150° | 170° |
|---|---|---|---|---|---|---|---|---|---|
| 精确区域面积（归一化） | 5.996 | 2.952 | 2.008 | — | 1.155 | **1.000** | 1.154 | 1.999 | 5.757 |
| Monte-Carlo `√det Cov`（归一化） | 5.923 | 2.955 | 2.018 | — | 1.162 | **1.000** | 1.160 | 2.008 | 5.835 |
| 理论 `1/sinα`（归一化） | 5.759 | 2.924 | 2.000 | — | 1.155 | **1.000** | 1.155 | 2.000 | 5.759 |

三组结果彼此吻合（比值 0.9999~1.04，`α < 20°` 时的偏差来自"窄带近似"在近距离的修正），**最小值都精确落在 90°**。

**（4）重要的适用范围提醒（与问题 2 的衔接）**

"90° 最好"是在**两条视线到目标的距离 `r₁, r₂` 固定**的前提下成立的。一旦允许自由移动第二点，改变位置会**同时**改变 `r₂` 和 `α`；再加上 `r` 未知，就必须做折中。由 `sin α = L sinφ/r₂` 可解出：

```
α = 90°  ⟺  L·cos φ = r        （r = 源到 S₁ 的距离）
```

而 `r` **正是未知量** —— 这解释了为什么问题 2 的最优偏角 `φ* ≈ 20°` 而不是 90°：**我们不能也不该直接把交会角摆成 90°，而是在 r 的不确定性下取折中。**

## 2. 问题 2：第二个检测点的选择策略与候选区域

### 2.1 目标函数：定位区域面积（GDOP）

设已测得 `S_1` 处示向度 `θ_1`。源 `G` 位于该射线上、距离 `r` **未知**（仅知 `r ≤ R ≤ 1500`）。
第二点 `S_2 = S_1 + L·(cos(θ_1+φ), sin(θ_1+φ))`，即**距 `S_1` 为 `L`、相对示向度偏角 `φ`**。

在源附近，每个楔形近似为一条"**宽 2εr 的窄带**"，两条窄带夹角为交会角 `α`（= 源处 `S_1`、`S_2` 的张角），故

```
面积  A ≈ (2εr₁)(2εr₂) / sin α = 4ε² · r · r₂ / sin α
```

其中 `r₂ = |S_2 − G|`。又由正弦定理 `sin α = L·sin φ / r₂`，代入得

```
A ≈ 4 ε² · r · r₂² / ( L · sin φ )
```

**三个直接结论：**

1. `A ∝ 1 / sin α` → **交会角越接近 90° 越好**（这就是交会定位的 GDOP 效应）。
2. **φ → 0（沿示向度方向前进）或 φ → 180° 时 `sin φ → 0`，区域发散**。→ **绝对不要把第二点放在示向度射线上！** 这是最容易犯的错。
3. `r` 未知 ⇒ 必须按**不确定性**做鲁棒设计。注意：若 `r` 已知，最优会退化到"直接走到源上"（`S_2 → G`），说明**问题本身必须引入 `r` 的先验**才有非平凡解。

### 2.2 最优设计（含数值结果）

对 `r` 取先验、最小化期望面积 `E[A]`：

| `r` 先验 | 最优 `L*` | 最优 `φ*` | `E[A]` |
|---|---|---|---|
| 均匀 `U(0,R)` | `≈ 0.70 R` | `≈ 20°` | `≈ 650 m²` |
| 面积权重（源在圆内均匀） | `≈ 0.77 R` | `≈ 14°` | `≈ 710 m²` |

**灵敏度**（均匀先验，ε = 1°，R = 1500 m）：

| `φ` | 10° | 20° | 30° | 45° | 60° | 90° | 120° |
|---|---|---|---|---|---|---|---|
| `E[A]` (L=1060 m) | 800 | **648** | 713 | 916 | 1185 | 1942 | 3300 |

可见 `φ ∈ [20°, 45°]` 很平坦，`φ → 0` 与 `φ > 90°` 迅速恶化。

**工程建议（论文与代码都用这一条）**

```
L ≈ 0.7 ~ 0.8 · R_max ≈ 1000 ~ 1200 m
φ ∈ [30°, 60°]（折中鲁棒，兼顾 r 的不确定性与"仍能收到信号"）
```

补充约束：`S_2` 必须仍在源的接收范围内（`r₂ ≤ R`）才能读到示向度。若 `S_2` 返回 `no_signal`，就**沿当前示向度方向缩短 `L` 重测**（在线修正，不要一次到位）。

> 更"鲁棒"的另一套提法（可作对照）：用 maximin 思想，选择 `S_2` 使 `min_{r≤R} sin α` 尽量大，等价于让"最坏情况下"的交会角不至于太小。两套提法结论一致：**避开近共线，取中等偏大的偏角与约 0.7R 的距离**。

### 2.3 候选区域

把候选区域定义为**性能水平集**：

```
C = { S_2 : E_r[ A(S_2) ] ≤ λ · min E_r[A] }        （例如 λ = 2）
```

其形态（见前文示意图）：**以 `S_1` 为顶点的"扇环"**

- 距离方向：`L ∈ [0.5R, 1.2R]`；
- 方位方向：`θ_1 ± φ`，`|φ| ∈ [15°, 75°]`；
- **剔除 `|φ| < 10°` 的近共线退化楔形**（H 形禁区）。

### 2.4 算法

```
输入: S1, θ1, R_max = 1500, 先验 p(r)
1) 在极坐标网格 (L, φ) 上离散化
2) 对每个 (L, φ):  E[A] ≈ Σ_k p(r_k) · 4ε² r_k r₂² / (L sinφ)
3) S2* = argmin E[A];  候选区域 C = 水平集 {E[A] ≤ λ·min}
输出: S2* 与 C
```

**机器人里的迭代版（与问题 3 衔接）**

```
while diam(K) > 阈值:
    在 K 之外、按"垂直于当前示向度方向、距离 ≈ 当前估计 r̂ 的 0.7~1.0 倍"取新测点 S_new
    S_new ← 加约束 → 更新 K   （调用问题 1 的算法）
```

## 3. 问题 3：全向干扰源的自动搜索—定位—清除策略

### 3.1 分层框架

| 层 | 职责 |
|---|---|
| L0 通信/时间 | 串行请求、`request_id` 幂等、虚拟时间记账、`remaining_real_duration_s` 预算 |
| L1 侦察 | 找出**哪些频道有源** + 粗方位 |
| L2 定位 | 多站 AOA 交会（**复用问题 1 的算法**），维护每频道约束集与区域 `K_c` |
| L3 逼近清除 | 迭代缩小 `diam(K_c)` 直至可清除，执行 `/clear` |
| L4 验证终止 | 排查漏检频道、判定总数、`/exit` |

### 3.2 关键子算法

**(1) 频道侦察。** 在侦察点对 20 个频道逐次 `/measure`。
成本 ≈ `20 × 5 + ≤19 × 1 ≈ 119 s`。
得到：有信号频道集合 + 各频道方位。**注意：`no_signal` 不能直接判定"无源"**，因为可能是超出接收半径（问题 4 还可能是定向不覆盖）。

**(2) 多站交会定位。** 把同一频道来自不同测点的 `(S_i, θ_i)` 送入问题 1 的算法，得到区域 `K_c`；**每新增一次测量就更新一次**，用 `diam(K_c)` 作为收敛判据。

**(3) 迭代逼近（核心）。**
- 由 `K_c` 取估计点 `Ĝ_c`（质心 / 区域内最优点）；
- 若 `diam(K_c) ≤ 30 m`（留安全裕度）→ 直接 `/clear(Ĝ_c, c)`；
  - `success` → 该源完成；
  - `no_target_in_range` → 在 `K_c` 内换点重试，或微移后重测再估计；
- 否则向 `Ĝ_c` 移动，**途中每隔一定步长重测**（且先后测点不能共线），持续收紧 `K_c`。
- **收敛原理**：`A ∝ r₁r₂/sin α`，逼近时 `r` 减小 ⇒ 区域面积**平方级下降**，收敛很快。

**(4) 近距触发（白送的信息）。** 若 `/measure` 返回 `near` ⇒ 距源 ≤ 5 m ⇒ **原地 `/clear` 必定成功**（≤ 20 m）。这是最省时的收尾方式。

**(5) 验证。** 对未清除频道，从 **≥ 2~3 个不同方位**侦察；全部 `no_signal` 才判定"无源"。
覆盖性要求：目标域半径 1800 m 而接收半径只有 1000~1500 m ⇒ **单点覆盖不了全圆**，侦察点需分布在半径约 1000~1200 m 的多点（如六边形顶点 + 原点）。

**(6) 终止。** 所有频道"已清除"或"确认无源" → `/exit`。

### 3.3 时间成本优化（这是得分关键）

总虚拟时间 = 移动 + 切换 + 检测 + 清除。**移动最贵（5 m/s），检测次之（5 s/次）**。

1. **减少无谓移动**：优先用远距离 AOA 粗定位，再逼近；不要盲目扫描全区域。
2. **把 `/clear` 当廉价探针**：未命中只 **3 s**（< 5 s 的检测），且**不切换频道**。估计已较准时，用它确认比再测一次方位更便宜。
3. **批量同点测量**：一个侦察点同时服务多个频道、多个源，摊薄移动成本。
4. **减少切换**：同点把要测的频道排序后连续测。
5. **不要在同一点重复测同一频道**（固定偏差 ⇒ 结果相同）。
6. **不要沿示向度方向设置下一个测点**（共线退化 ⇒ 区域不收敛）。
7. 若时间/预算将尽：**优先保证 `/exit` 被调用**（正式日志已入队即会继续上传）。

### 3.4 伪代码（主循环）

```python
enter();  T0 = 0
active = []            # 判定有信号的频道
K = {}                 # 频道 -> 定位区域
cleared = set()

# ---- L1 侦察 ----
for V in vantage_points:                 # 见 3.2(5)
    move_to(V)
    for c in channels_by_current_order:  # 减少切换
        r = measure(V, c)
        if r.result == "direction":
            K[c] = K.get(c, EMPTY) ∩ wedge(V, r.svd_deg, eps=1)
            active.append(c)
        elif r.result == "near":
            clear(V, c); cleared.add(c)

# ---- L2+L3 定位并清除 ----
for c in active if c not in cleared:
    while diam(K[c]) > 30:
        P = choose_next_point(K[c], theta_hat=centroid_direction(K[c]))  # 问题2策略
        move_to(P); r = measure(P, c)
        if r.result == "direction":  K[c] = K[c] ∩ wedge(P, r.svd_deg, eps=1)
        elif r.result == "near":     clear(P, c); break
    else:
        Phat = centroid(K[c])            # while 条件不成立时进入
        if clear(Phat, c) == "no_target_in_range":
            refine_and_retry(c)          # 微移重测后重试
        else:
            cleared.add(c)

# ---- L4 验证并退出 ----
for c in channels if c not in cleared:
    if all(measure(V, c).result == "no_signal" for V in verify_points):
        pass                             # 判定无源
if time_budget_ok(): exit()
```

### 3.5 统计口径（按表 1 填写）

- **被清除比例** = 被清除个数 / 干扰源总数。
  - 演练测试模拟器结束时会给出总数，可直接算；
  - **正式测试不显示真值**，用你自己判定出的频道个数作分母。
- **平均定位清除时间** = 定位清除总时间 / 被清除个数。
  - 由于虚拟时钟在 `/enter` 时为 0、只在 `/measure` 与 `/clear` 时推进，**总时间 = 最后一次动作的 `virtual_time_s`**，直接读取即可，无需累加。
- **程序运行时间** = `/enter` 成功到测试结束的现实时长（≤ 20 min）。
- 三次正式测试后从模拟器**导出加密日志**（**不要改文件名**）放入支撑材料。

**推荐的五步闭环**（本工作区已实现为 `p3_arena.py` + `p3_robot.py`）：

```
⑤ 连真实模拟器 → python p3_robot.py live --url http://127.0.0.1:2026 --team <队号>
```

**实测迭代记录**（问题 3，全向源，每局 10~16 个源）：

| 迭代 | 改动 | 平均定位清除时间 | 清除比例 |
|---|---|---|---|
| 基线 | 按频道号顺序处理，步长 0.7×距离、偏角 55° | 708 s | 1.000 |
| 迭代 1 | 选点改为**以当前位置为基准**（原先以旧测点为基准，导致来回跳） | 695 s | 1.000 |
| 迭代 2 | 加**最近邻排序** + 步长 1.0×距离、偏角 20°、上限 1500 m | **471 s** | 1.000 |
| 迭代 3 | 参数扫描后取偏角 10°、收敛阈值 40 m | **422 s** | 1.000 |
| **独立验证** | 换成 20 个全新 seed（未参与调参） | **490 s** | **1.000（20/20 满分）** |

**扫描揭示的关键结论（这类结论比"哪个参数快"更有价值）**：

- `k_ring = 1`（只有一个侦察环上的点）→ 清除比例掉到 **0.966**，出现漏源；`k_ring = 3` 才稳定为 1.000。
  **即：侦察点的覆盖性决定"正确性"，其余参数只影响"效率"。调参必须先把正确性调到位。**
- 偏角越小越快（15°→435 s，40°→610 s），因为侦察阶段已经给出不错的初始估计，逼近阶段"直冲"即可；
  但**不能取 0**：偏角为 0 时两次观测近乎共线，交会角退化，区域不收敛（见 1.5 节）。
- 收敛阈值放宽到 40 m 反而更快且不影响清除（质心到真值通常 <20 m，仍在清除半径内）。

**演练测试的纪律**：

1. **先把"清除比例 = 1"做到，再优化时间**。漏一个源的代价远大于慢一点。
2. **正式测试不显示真值**，所以演练测试时要用模拟器给出的总数核对"我判定出的频道个数"是否一致，
   把这个"自判个数"的逻辑调到 100% 正确。
3. 正式测试每题只有 3 次机会，"中止测试"也占一次，**所以参数必须在离线模拟器里调完再上**。
4. 每次演练都留意**加密日志大小 ≤ 2 MB**（正常策略几乎不会超，出现异常高频循环才会超）。

### 3.7 干扰源的空间分布有规律吗？

**结论：题目正文与两个附件都没有规定干扰源的空间分布**，只给了三条硬约束：

```
(1) 10 ≤ N ≤ 16，N 具体值未知
(2) 每个干扰源都在半径 1800 m 的圆域内
(3) 频道互不相同，从 20 个频道中取
```

除此之外（位置是否均匀、是否成簇、是否偏爱边缘）**都是未知的**。

**因此正确做法不是"猜一个分布"，而是三条并进：**

**（1）设计对分布不敏感的鲁棒策略。** 本策略不依赖任何位置先验：
侦察阶段用"原点 + 等角分布侦察环"保证**覆盖性**（与分布无关），
定位阶段靠实测算得的示向度，逼近阶段靠最近邻排序自动适应任何聚集/分散形态。
压力测试结果（每格 6 局，同一套参数）：

| 分布假设 | 含义 | 清除比例 | 平均定位清除时间 |
|---|---|---|---|
| `uniform_disk` | 圆内面积均匀（径向密度 ∝ r） | **1.0000** | 393 s |
| `uniform_radius` | 半径均匀（中心更密） | **1.0000** | 383 s |
| `boundary` | 边缘环带 0.85R~1.0R（最难被发现） | **1.0000** | 474 s |
| `center` | 中心集中（≤0.35R） | **1.0000** | 251 s |
| `clustered` | 3 个簇 | **1.0000** | 329 s |

**5 种分布全部做到 6/6 完美、清除比例 1.0000**，仅有耗时的差异（最难的 edge 情形也只比均匀情形差约 20%）。
这说明策略的**正确性不依赖分布假设**，可以直接说"对分布鲁棒"。

**（2）用演练数据反推真实分布（可写进论文的加分点）。**
关键观察：**一旦某局做到 ratio = 1，就说明该局的干扰源被我们全部找到了** ——
此时"我们记录到的源坐标集合"就是该局的**完整样本**，**不存在选择性偏差**（这一点很重要，
否则"我们只在找过的地方发现源"会带来严重偏差）。于是可以把每局清掉的源坐标记下来，
累积若干局后做标准空间统计检验：

| 检验 | 方法 | 判别 |
|---|---|---|
| 计数分布 | N 的直方图 | 是否 10~16 上均匀 |
| 径向密度 | 归一化 ρ=r/1800 的分箱占比 | 与圆内均匀理论 `b²−a²` 比较，做卡方检验 |
| 聚集性 | 平均最近邻距离 vs 泊松理论 `0.5/√λ` | Clark–Evans 指数 R：>1 规则、≈1 随机、<1 聚集 |

在本工作区用本地模拟器演示（300 局）的结果：

| 生成分布 | 径向密度卡方（9 自由度） | Clark–Evans R | 判别 |
|---|---|---|---|
| 圆内均匀 | **3.80**（临界值 16.92@5%） | 1.098 | 不能拒绝"圆内均匀" |
| 3 簇 | **3356.93**（远超临界值） | 0.584 | 强聚集 |

可见这套流程**确实能把"均匀"和"聚集"区分开**。接到真实模拟器后，把同样的三步跑一遍即可反推它的真实分布，
再据此调整侦察环的半径与点数（例如若发现是"边缘环带"，就把侦察环半径从 1100 m 改到 1400 m）。

> 两点技术提醒：
> ① 最近邻统计有**边缘效应**（靠近边界的点邻域被截断，会把 R 抬高），严谨做法要用边缘校正版本（如 Donnelly 校正）；
> ② 只统计 **ratio = 1** 的那些局，否则样本有偏。

## 4. 问题 4：含定向干扰源的策略增量

### 4.1 与问题 3 的差异

- 定向源只在**定向方向 ±90°（共 180°）**的半平面内辐射，之外 `/measure` 返回 `no_signal`。
- 后果：
  1. `no_signal` **不再意味着"无源"**（可能只是被"背向"了）；
  2. 单点侦察会**漏检**；
  3. 逼近途中可能**丢失**目标（越过覆盖边界）。
- 好消息：`/clear` 的成功**只与距离有关**（≤ 20 m），**与定向朝向无关** ⇒ 难点全部集中在"发现与定位"。

### 4.2 策略增量（4 条）

1. **多方位侦察。** 每个候选频道至少从 **2~3 个方位、张角 ≥ 120°** 处测。因为覆盖为 180° 半平面，"对向"两侧观测可保证**至少一侧可见**。
2. **丢失重捕。** 逼近时若由 `direction` 突变为 `no_signal`，说明越过了覆盖边界 ⇒ 做**横向 side-step** 绕行后重新捕获，不要直接放弃。
3. **边界法定位（亮点，建议写进论文）。** 覆盖边界是**过源的一条直线**。沿路径探测 `signal ↔ no_signal` 的**跃变点**必落在该直线上；两条不同路径给出两条过源直线，**交点即源位置**。可与常规 AOA 交会**联合估计**（作为额外的半平面约束加入 `K_c`）。这是定向源相对全向源"多出来"的信息，用得好是加分项。
4. **定向方向估计（可选）。** 绕疑似源位置做**环测**，记录"有/无信号"的方位区间，其两个边界即定向方向 `±90°`，从而反推 `φ_c`；论文中可作为对定向源的完整刻画。
5. **验证更谨慎。** 未清除频道必须从**多个方位**确认无信号，避免把"背向"误判为空。

### 4.3 与问题 3 的统一

主流程完全沿用问题 3（含问题 1 的定位内核与问题 2 的选点策略），只做三处升级：

- 侦察覆盖：单点 → **多方位**；
- 判空规则：单点 `no_signal` → **多方位 `no_signal`**；
- 定位约束：增加**覆盖边界半平面**作为新的约束来源。

## 5. 工程实现要点（协议与鲁棒性）

**协议**

- 只有 4 条指令：`/enter`、`/measure`、`/clear`、`/exit`；`POST`、`Content-Type: application/json`、路径不带尾斜杠与查询参数。
- 移动与切换频道**没有独立指令**：由 `/measure` 或 `/clear` 的 `position` 与 `/measure` 的 `channel` 推断。
- `/clear` 的 `channel` 是"目标源频道"，**不切换测向机频道、不产生切换耗时**。
- 必须**同时检查 HTTP 状态码与 `accepted`**；`accepted=false` 时 `virtual_time_s` 为 0，**不能当作当前虚拟时刻**。
- **每个新动作换新 `request_id`；仅重试同一动作时复用原 ID 与原请求体**（否则 HTTP 409）。
- **严格串行**，不得并发发送不同动作。响应含未知字段时返回 `accepted=false`（可用于排查拼写错误）。
- 处理"连不上"与"收到 JSON"两种失败；倒计时期间与测试结束后接口未开放属正常。

**时间与数值**

- 用 `/enter` 返回的 `remaining_real_duration_s` 控制现实预算，**不要假定每次都是 1200 s**；晚于倒计时后 5 min 进入会用不足 20 min。
- 虚拟时间**不消耗现实时间**（5 s 检测无需真实等待），所以现实瓶颈只有自己的计算与网络往返。
- 角度归一化到 `[0,360)`；坐标分量绝对值 ≤ 2×10⁶；`virtual_time_s` 是可能带小数的 number，别按整数解析。
- **必须自行记录指令序列与响应**（模拟器不提供该日志）；避免异常高频循环（加密日志 ≤ 2 MB）。

**截止时间**

- 北京时间 **2026-09-13 17:30** 之后不能启动新的演练/正式测试；建议 **15:30 之前**完成全部正式测试。
- 演练测试不限次数，正式测试每题**各 3 次**，且"中止测试"同样占用一次机会。

## 附：可直接复用的公式清单

- **扇形（楔形）半平面表示**：`n̂(α) = (−sinα, cosα)`；
  保留 `(P − S_i)·n̂(θ_i − ε) ≥ 0` 且 `(P − S_i)·n̂(θ_i + ε) ≤ 0`。
- **定位区域**：`K = ⋂ W_i ∩ D ∩ ⋂ disk(S_i, 1500)`，凸多边形，顶点数 ≤ 2n。
- **区域面积（两站）**：`A ≈ 4ε² r₁ r₂ / sin α`，`ε = 1° = 0.017453 rad`。
- **交会角关系**：`sin α = L·sin φ / r₂`，`r₂² = r² + L² − 2rL·cos φ`。
- **平行四边形覆盖引理**：较长对角线为直径的圆覆盖整个平行四边形。
- **Jung 定理**：`d/2 ≤ r* ≤ d/√3`；以 `d` 为直径可覆盖 ⟺ `r* = d/2`。
- **超额量统计量**：`E = 2r*/d − 1 ≥ 0`；`E = 0 ⟺ 能覆盖`。**检验覆盖性时应报告 `E` 的分位数，而不是只数失败次数。**
- **覆盖性分层结论**：`n = 2` → 可认为能覆盖（19 万例最大 `E = 5.9e−4`）；`n ≥ 3` → **不能保证**，区域可退化为锐角三角形，最坏 `E = 2/√3 − 1 = 15.47%`。
- **两站最优第二点**：`L* ≈ 0.7R`（均匀先验）或 `0.77R`（面积先验），`φ* ≈ 15°~20°`；工程取 `L ≈ 0.7~0.8R`、`φ ∈ [30°,60°]`。
- **有效接收距离**：`R ∈ [1000, 1500] m`；近距阈值 5 m；清除半径 20 m。
